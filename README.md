# Student Performance & Curriculum Tracker

## Overview
A full-stack web application designed to help students organize, track, and manage their academic courses, credit hours, completion statuses, and grades.

## Web Software Features
* **Full-Stack Integration:** React + TypeScript frontend communicating with a RESTful Express + SQLite backend.
* **Persistent Storage:** Local SQLite database storing course information.
* **CRUD Operations:** Ability to view, add, and delete course records in real time.

## Development Environment
* **Frontend:** React, TypeScript, Vite, Axios
* **Backend:** Node.js, Express, TypeScript, `tsx`
* **Database:** SQLite3
